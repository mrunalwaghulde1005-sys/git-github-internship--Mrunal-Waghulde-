# Simple Login Page

A beginner login form built with HTML, CSS, and JavaScript.

## Run

Open `index.html` in a browser. No build tools or dependencies are required.

## Trainer Walkthrough

- `index.html` creates the page: a heading, email field, password field, and submit button.
- `style.css` controls the colors, spacing, and responsive layout. The media query reduces padding on small screens.
- `script.js` listens for the submit, checks the email format and password length, then displays an error or success message.

You can explain it this way: “HTML builds the form, CSS makes it easy to use on different screen sizes, and JavaScript checks what the user entered. This is a front-end demo, so it does not send login details to a server.”
